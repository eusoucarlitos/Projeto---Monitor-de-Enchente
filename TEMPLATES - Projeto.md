## Perguntas interessantes para colocar no README

Um README, muitas vezes, é o primeiro item que um visitante verá ao visitar seu repositório. Os arquivos README geralmente incluem informações sobre:
<ul>
  <li>O que o projeto faz</li>
  <li>Por que o projeto é útil</li>
  <li>Como os usuários podem começar a usar o projeto</li>
  <li>Onde os usuários podem obter ajuda com seu projeto</li>
  <li>Quem mantém e contribui com o projeto</li>
</ul>
